# HH3 Ported Additions - Unbound Force

This repository contains a **single add-on BattleScribe catalogue** for the original Horus Heresy 1.0 game system.

It does **not** replace or clone the base HH1 catalogues. Install the normal HH1.0 data first, then add this repository.

## How it works

Create a force using:

**Unbound Force - HH3 Ported Additions**

The force has no HQ/Troops/Elites/Fast Attack/Heavy Support/Lords of War limits.

The only required selection is **Force Source**, used purely as a content filter:

- Legiones Astartes
- Mechanicum / Dark Mechanicum
- Questoris Knights
- Solar Auxilia
- Agents of the Emperor / Warmaster
- Daemons of the Ruinstorm

Once a source is selected, all ported units, rules and wargear for that source are offered with no legion, allegiance, Rite of War, Force Organisation or other legality restrictions.

Examples:
- Select **Legiones Astartes** to access Saturnine Terminators, Saturnine Praetor, Saturnine Dreadnought, Kratos, Chieftains, Procurators, Jorlund Hunters, Numerologist Cabal, Morlocks, characters, Primarch/Hereticus additions, Inductii, new Rites, warlord traits and disintegration additions.
- Select **Mechanicum / Dark Mechanicum** for Proscribed Techno-arcana, daemon engines, Malefic Cybertheurgy and Dark Mechanicum warlord rules.
- Select **Questoris Knights** for the Knight Preceptor and Dark Blessings.
- Select **Solar Auxilia** for the Aethon Sentinel, Cohort Doctrines and Legiones Auxilia.
- Select **Agents of the Emperor / Warmaster** for Assassins and the Infernus Abomination.
- Select **Daemons of the Ruinstorm** for Be'lakor.

## Important

This catalogue deliberately uses the **original HH1 gameSystemId** `ca571888-56a9-c58e-ddaf-54f4713538bc` so it appears as an additional army inside the original HH1 game system.

It does not include the original game-system file itself.

## Data index

After uploading this repository to GitHub, use the raw `index.bsi` URL as the BattleScribe data index.
